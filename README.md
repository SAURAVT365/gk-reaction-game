# KBC GK Reaction Game 🎯

This project is a KBC-style General Knowledge reaction game built using pure frontend technologies.

## Features
- 10 GK questions
- 4 multiple-choice options
- 10-second timer for each question
- Instant visual feedback (green for correct, red for wrong)
- No negative marking
- Score tracking (1 point per correct answer)
- Clean KBC-inspired UI
- No backend or database required

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)

## How to Run
1. Clone the repository or download the ZIP
2. Open `index.html` in any modern browser
3. Click **Start Game** and play

## Purpose
This project focuses on:
- JavaScript logic building
- Timer handling
- UI state management
- Event-driven programming
